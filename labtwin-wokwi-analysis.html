1. Phân Tích Dự Án Wokwi Tham Chiếu

1.1 Tổng Quan Dự Án ESP32 HTTP Server

Dự án mẫu sử dụng ESP32 DevKit C V4 để tạo HTTP Web Server điều khiển 2 LED (xanh dương + xanh lá) qua trình duyệt web. Đây là ví dụ điển hình cho IoT simulation trên Wokwi.

2.2 Open-Source Repos của Wokwi (github.com/wokwi)

avr8js

692 stars MIT License TypeScript

Arduino (8-bit AVR) simulator chạy trong browser/Node.js. Mô phỏng cycle-accurate CPU core, GPIO, Timers, USART, SPI, I2C, ADC, EEPROM, Watchdog.

Dùng cho Labtwin: Core engine cho Arduino Uno/Mega simulation.

rp2040js

493 stars MIT License TypeScript

Raspberry Pi Pico Emulator chạy trên JavaScript. Hỗ trợ ARM Cortex-M0+ instruction set.

Dùng cho Labtwin: Mở rộng hỗ trợ RP2040/Pi Pico boards.

wokwi-elements

229 stars MIT License TypeScript

Web Components (LitElement) cho 50+ linh kiện điện tử. SVG-based rendering, interactive, với pinInfo cho kết nối.

Dùng cho Labtwin: Toàn bộ thư viện SVG components!

esp8266js

46 stars MIT License TypeScript

ESP8266 Simulator viết bằng JavaScript.

Dùng cho Labtwin: Hỗ trợ ESP8266 boards.

wokwi-docs

180 stars MIT License

Documentation đầy đủ cho Wokwi Simulator. Mô tả chi tiết từng component, pin mapping, API.

Dùng cho Labtwin: Tham chiếu tài liệu kỹ thuật.

wokwi-cli

44 stars MIT License

Command Line Interface cho CI/CD testing.

Dùng cho Labtwin: Tham khảo cho headless simulation mode.

3.2 Cấu Trúc Một SVG Component (LED Element)

// led-element.ts - Cấu trúc LitElement + SVG
import { css, html, LitElement } from 'lit';
import { customElement, property } from 'lit/decorators.js';
import { ElementPin } from './pin';

const lightColors = {
  red: '#ff8080', green: '#80ff80', blue: '#8080ff',
  yellow: '#ffff80', orange: '#ffcf80', white: '#ffffff', purple: '#ff80ff'
};

@customElement('wokwi-led')
export class LEDElement extends LitElement {
  @property() value = false;         // ON/OFF state
  @property() brightness = 1.0;     // 0.0 - 1.0
  @property() color = 'red';        // LED color
  @property() label = '';           // Optional label
  @property() lightColor: string;   // Computed glow color

  // Pin definitions for circuit connections
  readonly pinInfo: ElementPin[] = [
    { name: 'A', x: ..., y: ... },   // Anode
    { name: 'C', x: ..., y: ... },   // Cathode
  ];

  render() {
    return html`
      <svg viewBox="...">
        <!-- LED body -->
        <circle .../>
        <!-- Glow filter when ON -->
        <filter id="glow">...</filter>
        <!-- Pin legs -->
        <line .../>
      </svg>
    `;
  }
}

4.3 Lộ Trình Triển Khai

  1. Phase 1: Foundation (2-3 tuần)
    Setup React + TypeScript project, tích hợp Monaco Editor, implement SVG canvas với zoom/pan, load wokwi-elements components, render circuit từ diagram.json
  2. Phase 2: Component System (2-3 tuần)
    Component palette (drag & drop), wire routing engine (Bezier curves), pin connection system, diagram.json editor, import/export projects
  3. Phase 3: Simulation Engine (3-4 tuần)
    Integrate avr8js cho Arduino simulation, Web Worker isolation, GPIO ↔ Component state binding, Serial Monitor, compile service (backend)
  4. Phase 4: Advanced Features (2-3 tuần)
    Thêm rp2040js cho Pi Pico, WiFi simulation, oscilloscope/logic analyzer view, multiple project support, sharing/collaboration
  5. Phase 5: Deploy & Polish (1-2 tuần)
    Cloud Run deployment, user authentication, project gallery, performance optimization, mobile responsive

6. Format diagram.json (Chuẩn Wokwi)

Cấu trúc Parts

{
  "type": "wokwi-led",        // Component type (maps to web component tag)
  "id": "led1",               // Unique identifier
  "top": 34.8,                // Y position (pixels)
  "left": -111.4,             // X position (pixels)
  "attrs": {                  // Component-specific attributes
    "color": "blue"           // LED color
  }
}

Cấu trúc Connections

[
  "esp:26",      // Source: component_id:pin_name
  "r1:2",        // Target: component_id:pin_name
  "green",       // Wire color
  ["h0"]         // Wire path hints (h=horizontal, v=vertical offset)
]

Special Connections

["esp:TX", "$serialMonitor:RX", "", []]  // $ prefix = virtual component
