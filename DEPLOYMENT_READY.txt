🚀 How to Deploy:
================

Step 1: Fix build issues
   mkdir -p docs/root-docs
   mv *.md docs/root-docs/ 2>/dev/null || true
   npm run build

Step 2: Prepare environment
   cp .env.local.example .env.local
   # Edit .env.local with your actual values
   nano .env.local

Step 3: Run deployment
   chmod +x deploy-aeroeduvision.sh
   ./deploy-aeroeduvision.sh

Step 4: Monitor deployment
   gcloud run services describe aeroeduvision --region=asia-southeast1
   gcloud run services logs tail aeroeduvision --region=asia-southeast1 -f

💡 Tips & Tricks:
================

- Use gcloud to manage secrets:
  gcloud secrets list
  gcloud secrets versions access latest --secret=DATABASE_URL

- Monitor service in real-time:
  gcloud run services logs read aeroeduvision --limit=50 --follow

- Update environment variables after deployment:
  gcloud run deploy aeroeduvision --update-env-vars KEY=VALUE --region=asia-southeast1

- Rollback to previous version:
  gcloud run deploy aeroeduvision --image gcr.io/.../aeroeduvision:previous

- Scale manually:
  gcloud run deploy aeroeduvision --min-instances 1 --max-instances 20 --region=asia-southeast1

🔍 Troubleshooting:
==================

Issue: "Cannot connect to Docker daemon"
Solution: Start Docker Desktop or Docker service

Issue: "Permission denied" errors
Solution: Check gcloud authentication and IAM roles
  gcloud auth login
  gcloud projects get-iam-policy gen-lang-client-0712182643

Issue: Build fails with module errors
Solution: Check package.json dependencies are installed
  npm ci --legacy-peer-deps

Issue: Deployment timeout
Solution: Check Cloud Run quotas and service account permissions
  gcloud run describe aeroeduvision --region=asia-southeast1
