## 1. NHÂN VẬT CHÍNH

### Tên: **Aero** (bé chuột chinchilla màu xám trắng, 6 tuổi)

**Ngoại hình:**
- Cao 60cm, lông mềm xám-trắng, đuôi to bồng bềnh
- Mắt to tròn đen, miệng cười hiền
- Áo phông màu vàng có chữ "Aero", quần short xanh dương
- Đeo balo nhỏ chứa "đồ thí nghiệm" (kính lúp, sổ ghi chép, bút màu)

**Tính cách:**
- Tò mò vô cùng — luôn hỏi "Vì sao?"
- Thông minh nhưng hay làm sai → có cơ hội học bài
- Tốt bụng, thích giúp đỡ bạn bè
- Yêu khoa học + tự nhiên

**Khẩu hiệu:** *"Aero thử xem nào!"*

### Nhân vật phụ:

| Tên | Vai trò | Đặc điểm |
|-----|--------|----------|
| **Bố Aero** | Người lớn dạy đạo đức | Bác sĩ, ôn tồn, biết nhiều |
| **Mẹ Aero** | Người lớn dạy đời sống | Đầu bếp, dịu dàng, kiên nhẫn |
| **Bí** (bạn thân) | Bạn cùng tuổi đối lập | Mèo nhỏ, nóng tính, thẳng thắn |
| **Cô Hươu** | Giáo viên mẫu giáo | Hươu cao cổ, biết nhiều câu chuyện |
| **Bác Cú** | Nhà bác học | Cú đeo kính, biết khoa học sâu |

## 2. CẤU TRÚC SERIES

### Format mỗi tập:
- **Thời lượng**: 6-8 phút (vừa với attention span của trẻ 4-10t)
- **3 phần** (chuẩn Three-Act Structure):
  1. **Mở đầu (1-2 ph)**: Aero gặp vấn đề/thắc mắc trong ngày
  2. **Khám phá (3-5 ph)**: Aero thử-sai-được giúp đỡ
  3. **Bài học (1-2 ph)**: Aero kể lại bài học + tương tác với người xem

### Bonus tương tác (game element):
- **3 câu hỏi cuối tập**: HS trả lời để unlock badge
- **Bộ sưu tập**: 10 badge = 1 sticker pack mới
- **Daily streak**: xem 7 tập liên tiếp = unlock skin Aero "Phi hành gia"

## 4. KIẾN TRÚC KỸ THUẬT

### Stack đề xuất:

**Animation:**
- **Adobe Animate / Toon Boom Harmony** — chuẩn industry 2D
- Hoặc: **Procreate Dreams** (iPad) — rẻ hơn cho mới bắt đầu
- Hoặc: **Krita + OpenToonz** (free) — open source

**Audio:**
- **ElevenLabs Vietnamese voice** — voice acting tự động
- **AIVA / Suno** — nhạc nền
- **Audacity** — edit + master

**Game shell (trong app inphysic):**
- React component `<KidGamePlayer />` đặt trong `aeroedu-vite/src/components/kids/`
- Render video MP4/HLS + overlay quiz cuối tập
- State management qua Zustand (đã có)
- Save progress + badge vào `UserProfile.kidProgress` JSONB

**Route đề xuất:** `/kids/aero` (đăng nhập tài khoản phụ huynh hoặc HS tiểu học)

### Cấu trúc dữ liệu:

```typescript
interface AeroEpisode {
  id: string                    // 's1e1-rua-tay'
  season: 1 | 2 | 3 | 4 | 5
  episode: number               // 1-10
  title: string
  skill: string                 // "Rửa tay đúng cách"
  ageGroup: '4-5' | '5-6' | '6-7' | '7-9' | '9-10'
  videoUrl: string              // GCS bucket URL
  thumbnailUrl: string
  duration: number              // giây
  quiz: AeroQuiz[]              // 3 câu cuối tập
  badge: {
    id: string
    name: string                // "Aero Vệ Sinh Giỏi"
    imageUrl: string
  }
  unlocksNext?: string          // ID tập tiếp theo
  parentNote?: string           // Hướng dẫn cho PH cùng xem
}

interface AeroQuiz {
  question: string
  type: 'tap' | 'choice' | 'match'
  options?: { text: string; correct: boolean; image?: string }[]
  matchPairs?: { left: string; right: string }[]
  feedback: { correct: string; wrong: string }
}
```
