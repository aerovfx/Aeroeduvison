## 4. KIẾN TRÚC PRODUCTION

### Đội ngũ sản xuất:
- 1 Editor-in-Chief (full-time)
- 2 Writers (1 chuyên truyện, 1 chuyên nội dung khoa học) — freelance/quyển
- 3 Illustrators (style Aero chinchilla nhất quán)
- 1 Designer layout (Adobe InDesign)
- 1 Editor tiếng Việt
- 1 Project Manager kết nối in ấn

### Tech stack hỗ trợ:
- **Writing**: Notion + Google Docs collab
- **Illustration**: Procreate + Adobe Illustrator
- **Layout**: Adobe InDesign
- **Print prep**: PDF/X-1a 300dpi CMYK
- **Print partner**: NXB Kim Đồng OR Đông Á partnership

### Pipeline 1 quyển (Line B = 28 trang):
- Tuần 1-2: Outline + script
- Tuần 3-5: Illustration 28 trang
- Tuần 6: Layout + edit
- Tuần 7: Proof + sửa
- Tuần 8: In thử + duyệt
- Tuần 9-10: In hàng loạt 2000 bản

→ **1 quyển = 10 tuần**. Pipeline song song 3 quyển/lúc → output 1 quyển/3 tuần.

## 7. NGÂN SÁCH

### Cost per book (avg Line B 28 trang):
- Writer: 5tr
- Illustrator (28 trang × 1.5tr): 42tr
- Designer layout: 8tr
- Editor + proof: 4tr
- Print 2000 bản: 30tr
- **Tổng: 89tr/quyển**

### Tổng 36 quyển:
- Sản xuất: 36 × ~90tr = **3.24 tỷ**
- Marketing + launch: **400 triệu**

- **TỔNG: 3.84 tỷ trong 12 tháng**

### Doanh thu dự kiến:

- **Tổng: 8.8 tỷ — ROI 2.3x năm đầu**
