VẤN ĐỀ:
  ❌ Docker build fails
  ❌ Cloud Run rejects image
  ❌ "exec format error"

NGUYÊN NHÂN:
  Mac M1/M2 build ARM64
  Cloud Run cần AMD64

GIẢI PHÁP:
  2 cách deploy (chọn 1)

═══════════════════════════════════════════════════════════════

CÁCH 1: LOCAL BUILD (NHANH) ⚡
───────────────────────────────────────────────────────────────

Setup lần đầu:
  docker buildx create --name multiarch --use

Deploy:
  ./DEPLOY_AMD64_FIX.sh

Thời gian: 5-10 phút

Ưu điểm:
  ✅ Nhanh
  ✅ Không upload
  ✅ Phù hợp deploy thường xuyên

═══════════════════════════════════════════════════════════════

CÁCH 2: CLOUD BUILD (DỄ) ✅
───────────────────────────────────────────────────────────────

Setup lần đầu:
  gcloud services enable cloudbuild.googleapis.com

Deploy:
  ./deploy-cloudbuild.sh

Thời gian: 10-15 phút

Ưu điểm:
  ✅ Không cần Docker
  ✅ Build trên Google servers
  ✅ Dễ setup
