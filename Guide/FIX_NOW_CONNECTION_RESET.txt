TẠI SAO CRASH:
───────────────────────────────────────────────────────────────

Code hiện tại:
  lib/auth.ts uses PrismaAdapter(db)
  → Requires DATABASE_URL
  
Cloud Run:
  DATABASE_URL not set
  → Prisma fails to connect
  → Service crashes
  → ERR_CONNECTION_RESET

Fix:
  Switch to authOptionsSimple (no DB)
  OR
  Add DATABASE_URL to Cloud Run
