TẠI SAO CODE CŨ LỖI:
───────────────────────────────────────────────────────────────

Code cũ:
  const baseUrl = getBaseUrl();  // ❌ Cached!

Docker build:
  1. Import lib/auth.ts
  2. Run: const baseUrl = getBaseUrl()
  3. NEXTAUTH_URL not set → defaults to localhost
  4. baseUrl = 'localhost' cached
  5. Baked into Docker image

Runtime:
  1. Set NEXTAUTH_URL=https://inphysic.com
  2. Too late! baseUrl already cached
  3. Still uses localhost ❌
