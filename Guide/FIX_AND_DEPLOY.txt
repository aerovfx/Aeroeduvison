❌ DOCKER ERROR - DAEMON NOT RUNNING
═══════════════════════════════════════════════════════════════════

Error: Cannot connect to Docker daemon
Reason: Docker Desktop chưa khởi động

───────────────────────────────────────────────────────────────────
✅ FIX NGAY (3 BƯỚC):
───────────────────────────────────────────────────────────────────

1. MỞ DOCKER DESKTOP:
   Cmd+Space → gõ "Docker" → Enter
   
   Hoặc:
   Applications → Docker.app

2. ĐỢI DOCKER KHỞI ĐỘNG (~30 giây):
   - Nhìn icon Docker ở menu bar (góc trên phải)
   - Chờ icon từ "animated" → "normal"

3. VERIFY:
   docker info
   
   → Nếu thấy output → OK! ✅

───────────────────────────────────────────────────────────────────
🚀 SAU ĐÓ DEPLOY:
───────────────────────────────────────────────────────────────────

Option 1 (Recommended):
  ./START_DOCKER_AND_DEPLOY.sh

Option 2:
  ./DEPLOY_FIX_LOCALHOST_FINAL.sh
